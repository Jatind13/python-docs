How the lessons work

Run, change, break

Every code box is editable. Change it, run it, and break it on purpose: that is how the behaviour sticks.

See the machinery

Animations and live viewers show tokens, bytecode and the virtual machine, not just the rules.

Challenges that check

Challenges run your code against a hidden check and tell you what is off. Solved ones are remembered on this device.

Revise quickly
