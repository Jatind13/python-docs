Function arguments in depth

Python gives you a lot of control over how a function is called: by position or by name, with defaults, with any number of values. Here is the whole toolkit, plus the one default-value trap that bites almost everybody once.

Positional and keyword arguments

Arguments are matched to parameters by position, unless you name them. Named (keyword) arguments can come in any order and make calls easier to read.

Default values

Give a parameter a default and the caller may leave it out. Parameters with defaults must come after the ones without.

The mutable default trap

Default values are created once, when the def line runs, not on every call. With an immutable default (a number, a string, None) that never matters. With a list or dict, every call that uses the default shares the same object.

Rule: never use a list, dict or set as a default value. Use None and create the object inside the function. Linters flag this for a reason, and it is a favourite interview question.

*args: any number of positional arguments

A parameter with one star collects all the extra positional arguments into a tuple. The name args is only a convention; the star is what matters.

**kwargs: any number of keyword arguments

Two stars collect the extra named arguments into a dict.

The full order of parameters is: normal ones, then *args, then keyword-only ones, then **kwargs. Anything after *args (or after a bare *) can only be passed by name. That is useful for flags you want to be explicit at the call site:

Unpacking at the call: * and ** the other way round

In a call, the stars do the opposite: * spreads a list or tuple into positional arguments, and ** spreads a dict into keyword arguments.

lambda: tiny one-line functions

lambda params: expression makes a small unnamed function. Use it where you need a short function only once, most often as the key for sorting, min or max. If it needs a name or more than one line, write a normal def.

Challenges

Write average(*numbers) that returns the average of any number of arguments, and 0 if there are none.

Show solution
def average(*numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

register is supposed to give every new team its own member list, but the second team gets the first team's members too. Fix it.

Show solution
def register(member, team=None):
    if team is None:
        team = []
    team.append(member)
    return team

Print words sorted from the shortest to the longest, using sorted with a lambda as the key.

Hint

The key function gets one word and returns what to sort by: its length.

Show solution
words = ["banana", "fig", "apple", "kiwi"]
print(sorted(words, key=lambda w: len(w)))

Recap

  • Arguments match by position unless named. Positional ones come first in a call.
  • Defaults are evaluated once. Use None instead of a list, dict or set.
  • *args collects a tuple, **kwargs collects a dict. After *, parameters are keyword-only.
  • In a call, * and ** spread a sequence or a dict into arguments.
  • lambda is for short throwaway functions, mostly sort keys.
