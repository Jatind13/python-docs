Functions

A function is a named, reusable block of code. You write the logic once, give it a name, and call it wherever you need it. Functions are how small scripts grow into programs without turning into copy-pasted chaos.

Define once, call many times

def greet(name):          # def, a name, parameters in brackets, a colon
    print("Hello,", name) # the indented block is the body

greet("Asha")             # call it: name is "Asha" for this call
greet("Ravi")
WordMeans
ParameterThe variable name in the definition: name in def greet(name)
ArgumentThe actual value you pass in a call: "Asha" in greet("Asha")
Return valueWhat the call evaluates to. Without a return, it is None

Definition is not execution. When Python reads def, it only creates the function object and binds it to the name. The body runs only when you call it. So a function must be defined before the line that calls it runs.

return is not print

This is the number one beginner mix-up. print() shows something on the screen and throws it away. return hands a value back to whoever called the function, so they can store it, combine it, or pass it on.

return also ends the function immediately. Code after it, in the same path, never runs. That makes "early return" a clean way to handle special cases first:

Returning several values

Return them separated by commas. Python packs them into a tuple, and you can unpack it straight into variables.

Docstrings and the help you get for free

A string as the first line of the body is the function's docstring. Editors show it on hover, and help() prints it. Say what the function does, what it takes, and what it returns.

The : float and -> float are type hints. Python does not enforce them; they document intent and let editors and tools like mypy catch mistakes. Optional, but common in professional code.

Functions are objects too

A function name is just a variable that points at a function object, exactly like the names-and-objects picture from the memory lesson. So you can store a function in another variable, put it in a list, or pass it to another function. This idea powers sorted(key=...), closures and decorators later on.

Challenges

Write is_even(n) that returns True if n is even and False otherwise. Do not print inside it.

Hint

n % 2 == 0 is already True or False, so you can return it directly.

Show solution
def is_even(n):
    return n % 2 == 0

print(is_even(4), is_even(7))

Write min_max(numbers) that returns the smallest and the largest number as two values, without using the built-in min() or max().

Show solution
def min_max(numbers):
    low = high = numbers[0]
    for n in numbers[1:]:
        if n < low:
            low = n
        if n > high:
            high = n
    return low, high

low, high = min_max([4, 9, 1, 7])
print(low, high)

total_bill prints instead of returning, so the tip calculation crashes. Fix the function so the program prints Total with tip: 550.0.

Show solution
def total_bill(prices):
    total = 0
    for p in prices:
        total += p
    return total

bill = total_bill([200, 150, 150])
print("Total with tip:", bill * 1.1)

Recap

  • def name(params): creates a function; the body runs only when it is called.
  • return gives a value back and ends the call. No return means None.
  • return a, b returns a tuple, which you can unpack: x, y = f().
  • Docstrings and type hints document a function. Python does not enforce hints.
  • Functions are objects: you can store them in variables and pass them to other functions.
