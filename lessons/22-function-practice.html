10 function problems

Ten small problems that cover everything functions can do: parameters, return values, defaults, lambda, *args, **kwargs, and two new ideas introduced along the way, generators and recursion. The checker calls your function with several inputs, so printing the right answer is not enough: return it.

Warm-up: parameters and return

Write square(n) that returns n squared.

Show solution
def square(n):
    return n * n

Write add(a, b) that returns the sum.

Show solution
def add(a, b):
    return a + b

Write multiply(a, b) that returns a * b. Then run it with numbers and with a string and a number. The same code works for both because * means different things for different types. That is polymorphism, and it comes back in the OOP lessons.

Show solution
def multiply(a, b):
    return a * b

Write rectangle(length, width) that returns the area and the perimeter, in that order.

Show solution
def rectangle(length, width):
    return length * width, 2 * (length + width)

Write greet(name) that returns "Hello, Asha!" for greet("Asha"), and "Hello, Guest!" when called with no argument.

Show solution
def greet(name="Guest"):
    return f"Hello, {name}!"

Flexible functions

Create cube as a lambda that returns its argument cubed.

Show solution
cube = lambda x: x ** 3

Write sum_all so it accepts any number of numbers and returns their total. sum_all() returns 0.

Show solution
def sum_all(*numbers):
    return sum(numbers)

Write describe(**info) that returns the pairs as one string, like "name=Asha, age=25", in the order they were passed.

Hint

Build a list of f"{k}={v}" strings from info.items(), then ", ".join(...) it.

Show solution
def describe(**info):
    return ", ".join(f"{k}={v}" for k, v in info.items())

Two new ideas

Generators: functions that pause

Put yield in a function and calling it no longer runs the body. Instead it returns a generator, a lazy iterator (see how loops work). Each next() runs the body until the next yield, hands out that value, and pauses with all local variables kept. Great for long or endless sequences, because nothing is stored up front.

Write a generator evens(limit) that yields the even numbers from 0 up to and including limit.

Show solution
def evens(limit):
    for n in range(0, limit + 1, 2):
        yield n

Recursion: a function that calls itself

A recursive function solves a problem by calling itself on a smaller version of it. It needs two parts: a base case that stops (otherwise you get RecursionError), and a recursive case that moves towards it. Python allows about 1000 nested calls by default, so loops are usually better for large inputs; recursion shines for naturally nested data like trees and folders.

Write factorial(n) recursively (no loops): factorial(5) is 5 × 4 × 3 × 2 × 1 = 120, and factorial(0) is 1.

Hint

Base case: n is 0 or 1, return 1. Recursive case: n * factorial(n - 1).

Show solution
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))

What you can do now

  • Write functions that take exactly the arguments they need, with sensible defaults.
  • Return one value or several, and know why return beats print.
  • Accept any number of arguments with *args and **kwargs.
  • Produce values lazily with a generator, and solve nested problems with recursion.
