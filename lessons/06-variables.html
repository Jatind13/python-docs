What a variable is

A variable is a name that refers to a value. You create one by assigning with =. There is no declaration, and no type to write: the type belongs to the value, not the name.

Style: use snake_case for variables and make names descriptive (total_price, not tp). By convention, UPPER_CASE marks a value you intend not to change, such as MAX_RETRIES = 3. Python does not enforce it.

How variables work in memory

Think of a variable as a name tag attached to an object, not a box that contains a value. Values are objects living in memory. Assignment never copies the object. It just attaches a name to it.

a = [1, 2, 3]
b = a

a ──┐
    ├──▶  [1, 2, 3]      one list object, two names
b ──┘

Mutable and immutable

  • Mutable objects can change in place: lists, dictionaries, sets. This is why the example above surprised you.
  • Immutable objects cannot: numbers, strings, tuples. "Changing" one really creates a new object and moves the name to it.

Rules of thumb. Use == to compare values and is only for None (if x is None). To copy a list use b = a.copy() or list(a). These make a shallow copy, so nested lists inside are still shared. When no name points to an object any more, Python frees its memory automatically.

Recap

  • A variable is a name that refers to an object. The type belongs to the value.
  • Names: letters, digits, underscores, not starting with a digit, case-sensitive, snake_case by convention.
  • b = a never copies. Mutable objects (lists, dicts) change in place, immutable ones (numbers, strings, tuples) are replaced.
  • Use == for values, is None for None, and .copy() when you need a separate list.
