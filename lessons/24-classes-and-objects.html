Object-oriented Python

Classes and objects

You have been using objects since page one: "chai".upper() calls a method on a string object. A class lets you design your own kind of object, bundling the data (attributes) and the behaviour (methods) that belong together.

Your first class

What is self?

self is the object the method was called on. cup1.describe() is really Chai.describe(cup1): Python passes the object in as the first argument for you. The name self is a convention, but always use it.

__init__ is not the constructor, strictly speaking. The object is created first (by __new__), then __init__ initialises it. In everyday talk people call __init__ the constructor, and that is fine. Its job: give every new object the attributes it needs. It must return None.

Class attributes vs instance attributes

Attributes set on self belong to one object. Attributes written directly in the class body are shared by all objects. Python looks on the object first, then on the class.

Same trap as mutable defaults: a list as a class attribute (orders = [] in the class body) is shared by every object. If each object needs its own list, create it in __init__: self.orders = [].

Printing objects nicely: __str__ and __repr__

Methods with double underscores on both sides ("dunder" methods) hook your class into Python's built-in behaviour. The two you will write most:

MethodUsed byAim
__str__print(obj), str(obj), f-stringsReadable, for users
__repr__The REPL, lists of objects, debuggers, repr(obj)Unambiguous, for developers: ideally code that recreates the object

Challenges

Write a Rectangle class. Rectangle(3, 4) stores width and height, and has methods area() and perimeter().

Show solution
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

Write BankAccount(owner) that starts with a balance of 0. deposit(amount) adds to it. withdraw(amount) subtracts and returns True, but if there is not enough money it changes nothing and returns False.

Show solution
class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        self.balance = 0

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            return False
        self.balance -= amount
        return True

Give Student a class attribute total that counts how many students were created, and a __str__ so that print(Student("Asha", 91)) shows Asha: 91.

Show solution
class Student:
    total = 0

    def __init__(self, name, marks):
        self.name = name
        self.marks = marks
        Student.total += 1

    def __str__(self):
        return f"{self.name}: {self.marks}"

Recap

  • A class is a blueprint; each object (instance) has its own data.
  • __init__ sets up a new object's attributes on self.
  • obj.method() passes the object in as self.
  • Class attributes are shared; instance attributes belong to one object. Mutable data goes in __init__.
  • __str__ is for users, __repr__ for developers.
