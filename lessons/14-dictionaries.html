Data types in depth

Dictionaries

Store data as key-value pairs and look things up by name. Read, change and delete entries, loop over keys and values, build dictionaries in one line, and copy them safely.

10 min3 challenges3-question quiz

The basics

A dictionary maps keys to values: {"key": "value", ...}. You get a value by its key, not by a position. Keys must be unique and immutable (strings, numbers and tuples work, lists do not). Dictionaries keep the order in which items were added.

To...Use
Read a valued["a"] (a KeyError if the key is missing), or d.get("a", default)
Add or changed["c"] = "D"
Check a key exists"a" in d (checks keys, not values)
Remove a keydel d["a"], or d.pop("a") which also returns the value
Remove the last added paird.popitem()
Remove everythingd.clear()
Count the pairslen(d)

Looping: keys, values and items

Looping over a dictionary gives its keys. Use .values() for the values and .items() for both together: each item is a (key, value) pair that you can unpack into two names.

Building dictionaries quickly

A dictionary comprehension builds one in a single line: {key: value for item in sequence}. dict.fromkeys(keys, default) makes a dictionary with the same starting value for every key.

Copying: shallow vs deep

There are three different things people call "copying":

CodeWhat you get
alias = dNo copy at all: a second name for the same dictionary.
d.copy()A shallow copy: a new dictionary, but the values inside are still the same objects. A nested list or dictionary is shared.
copy.deepcopy(d)A deep copy: a new dictionary and new copies of everything nested inside.
menu     {"tea": ●}──┐
shallow  {"tea": ●}──┼──▶ ["Black", "Green"]   one shared list
deep     {"tea": ●}────▶ ["Black", "Green"]   its own copy

Rule of thumb. If the dictionary only holds numbers, strings and tuples, .copy() is enough. If it holds lists or other dictionaries and you will change them, use copy.deepcopy(). The same applies to lists.

Challenges

Use dict.fromkeys to print a dictionary with the keys a, b, c that all start at 0.

Show solution
keys = ["a", "b", "c"]
print(dict.fromkeys(keys, 0))

Print the total of all the prices in the dictionary (90). Use .values().

Hint

sum() adds up everything in a collection of numbers.

Show solution
prices = {"tea": 20, "coffee": 30, "juice": 40}
print(sum(prices.values()))

After the code runs, backup["tea"] must still be ["Black", "Green"] while menu["tea"] has "Lemon" added. Change only the backup line.

Show solution
import copy
menu = {"tea": ["Black", "Green"]}
backup = copy.deepcopy(menu)
menu["tea"].append("Lemon")

Recap

  • Dictionaries map unique, immutable keys to values. Use d[key] or d.get(key, default), and in checks keys.
  • Remove with del, pop(key), popitem() or clear(). Loop with the default (keys), .values() or .items().
  • Build with {k: v for ...} or dict.fromkeys(keys, default).
  • = shares, .copy() is shallow, copy.deepcopy() copies everything nested.
