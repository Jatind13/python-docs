Getting started

Install and set up

Get Python on your machine, isolate each project in a virtual environment, and set up VS Code so everything just works.

10 minDone on your own computerChecklist + quiz

1. Install Python

Download the latest Python 3 from python.org/downloads, or use your system's package manager.

Run the installer from python.org. On the first screen, tick "Add python.exe to PATH" before clicking Install. This is the step people miss, and it causes "python is not recognized" later. Then check it:

python --version
python -m pip --version

If python is not found, try py --version. The py launcher comes with the installer.

Run the installer from python.org, or if you use Homebrew run brew install python. On macOS the command is python3:

python3 --version
python3 -m pip --version

Most distributions include Python 3. On Debian or Ubuntu, make sure the venv and pip parts are installed too:

sudo apt update
sudo apt install python3 python3-venv python3-pip
python3 --version

2. Create a virtual environment

A virtual environment (venv) is a private folder of packages for one project. Without it, every project shares one set of packages, and upgrading a library for one project can break another. Make one venv per project.

From inside your project folder:

python -m venv .venv
.venv\Scripts\Activate.ps1        # PowerShell
.venv\Scripts\activate.bat        # Command Prompt (cmd)

If PowerShell refuses to run the script, run this once and try again: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.

python3 -m venv .venv
source .venv/bin/activate

When it is active, your terminal prompt starts with (.venv), and python and pip now refer to this project's private copies. The day-to-day commands:

python -m pip install requests              # install a package into this venv
python -m pip freeze > requirements.txt     # save the exact versions
python -m pip install -r requirements.txt   # recreate the environment elsewhere
deactivate                                  # leave the venv

Add .venv/ to your .gitignore. Commit requirements.txt, never the venv folder itself. Use python -m pip instead of plain pip so you are sure which Python the package goes to.

3. Set up VS Code

  1. Install VS Code.
  2. Open the Extensions panel (Ctrl + Shift + X) and install Python by Microsoft. It brings code completion and debugging with it.
  3. Use File, Open Folder to open your project folder (open the folder, not a single file).
  4. Press Ctrl + Shift + P, run Python: Select Interpreter, and choose the one inside .venv. VS Code often offers this automatically.
  5. Create hello.py, then click the Run triangle at the top right, or run it in the terminal. New terminals in VS Code activate the venv for you.

Two habits worth building now: click in the gutter next to a line number to set a breakpoint and press F5 to debug, and optionally install the Ruff extension for fast linting and formatting.

Do it on your machine

These steps cannot run in the browser, so tick them off as you go. Your ticks are saved on this device.

To confirm you are really using the venv, run this in VS Code. The path should contain .venv:

import sys
print(sys.executable)

Recap

  • Install Python 3 (tick "Add to PATH" on Windows) and verify with --version.
  • One venv per project: create with python -m venv .venv, activate, then python -m pip install.
  • In VS Code: install the Python extension, open the folder, and select the .venv interpreter.
