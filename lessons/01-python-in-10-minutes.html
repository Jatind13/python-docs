What is Python?

Python is a high-level, general-purpose programming language created by Guido van Rossum and first released in 1991. Its code reads close to plain English, so you spend your effort on the problem and not on syntax.

  • High-level: you do not manage memory or machine details yourself.
  • General-purpose: websites, data, AI, automation, scripts, testing, tools.
  • Dynamically typed: a variable can hold any type, and types are checked while the program runs.
  • Batteries included: a large standard library, plus hundreds of thousands of packages on PyPI.

Always use Python 3. Python 2 is long retired. Any recent 3.x release is fine for this refresher.

Why Python?

StrengthsTrade-offs
Easy to read and write, so you ship fasterSlower than C, C++ or Go for CPU-heavy loops
Dominant in AI, data science and automationNot the usual choice for mobile apps
Huge ecosystem: FastAPI, Django, pandas, PyTorchDynamic typing means some bugs only show at run time
Runs on Windows, macOS and LinuxOne thread runs Python code at a time (the GIL), so use processes or async for some workloads

The speed trade-off matters less than it sounds: libraries such as NumPy and PyTorch do the heavy work in compiled code, and Python just coordinates it.

How Python runs your code

The standard Python (called CPython) does two things when you run a file:

hello.pyyour source code
→
Compilechecks syntax, translates to bytecode
→
Runthe Python virtual machine executes the bytecode
→
Outputwhat print shows

Bytecode is a compact set of instructions for Python's own virtual machine, not for your CPU. You never see this step, and you do not need to manage it. Two practical consequences:

  • A syntax error stops the whole file before anything runs, because the compile step fails first.
  • A runtime error (like dividing by zero) only stops the program at the line where it happens. Earlier lines already ran.
