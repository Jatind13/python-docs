if, elif, else

An if runs its block only when its condition is True. Add elif (Python's spelling of "else if") for more conditions, and else for everything left over. Python checks from the top, runs the first branch that matches, and skips the rest.

  • The line ends with a colon :. Forgetting it is a SyntaxError.
  • The condition needs no parentheses: if age >= 18:.
  • elif and else are optional, and you can have many elif lines. Order matters, because the first match wins.

= assigns and == compares. if x = 5: is a syntax error. You want if x == 5:.

Writing conditions

A condition is anything that is true or false: comparisons (< > <= >= == !=), in checks, and combinations with and, or, not. Python also treats values as true or false ("truthiness"): zero, empty strings, empty collections and None count as False, everything else as True.

Indentation is the syntax

Most languages use braces { } to group code. Python uses indentation. A line ending in a colon opens a block, and every line indented underneath it belongs to that block. When the indentation goes back to the left, the block is over.

if x > 3:                    ← the colon opens a block
    print("A")               ┐ these two lines are
    print("B")               ┘ the block (indented)
print("C")                   ← back at the left edge: the block has ended

Run it, then change x to 1 and run again. Lines A and B vanish together, because they are one block. Line C always runs.

Now see how moving a single line changes the meaning. Here line B is dedented, so it is no longer part of the if. Set x = 1 to see it still print.

The rules

  • Use 4 spaces per level. Every line in one block must have the same indentation.
  • Do not mix tabs and spaces. In VS Code, the Tab key inserts spaces for Python files.
  • Blocks can nest: indent again inside a block to start a block inside it.
  • A block needs at least one line. A colon with nothing indented below it is an error.

expected an indented block after 'if' statementNothing is indented under the colon line

Nested conditions and the one-line form

Indent again inside a block to nest decisions. For a simple either/or value, a conditional expression fits on one line: value_if_true if condition else value_if_false.

Recap

  • if / elif / else: each ends with a colon, and the first matching branch runs.
  • Conditions use comparisons, in, and, or, not. Zero, empty values and None are false.
  • Indentation defines blocks: 4 spaces, the same level for the same block, and dedenting ends it.
  • Nest blocks by indenting again. Use a if cond else b for a simple one-line choice.
