How loops work behind the scenes

A for loop looks simple, but it runs on a small protocol of two functions: iter() and next(). Once you see it, a lot of Python suddenly makes sense: why a zip works only once, why range(10**12) costs nothing, and why removing items while looping skips some.

Iterable vs iterator

What it isAnything you can loop overThe object that does the looping: it hands out one value at a time

Think of a list as a book and an iterator as a bookmark. You can put many bookmarks in one book, and each one remembers its own page.

What a for loop really does

1. iter(obj)Ask the iterable for a fresh iterator
→
2. next(it)Get the next value and run the loop body with it
→
3. repeatCall next() again
→
4. StopIterationNo values left: the loop ends quietly

Why this matters: anything that follows this protocol works in a for loop, in list(), sum(), max(), in, unpacking (a, b = ...) and comprehensions. They all call iter() and next() under the hood.

Iterators are single-use

An iterator remembers where it is, and it never rewinds. This catches people out with zip, map and enumerate, which return iterators, not lists.

Need to loop over a zip or map twice? Turn it into a list once: pairs = list(zip(a, b)).

Lazy on purpose: range, files and generators

An iterator works out each value only when next() asks for it. That is why range(10**12) does not build a trillion numbers, and why you can read a 10 GB log file line by line with a plain loop.

Looping over dictionaries

Looping over a dict gives its keys. Use .items() for key and value together, or .values() for values only. These are live views, not copies.

Two classic pitfalls

1. Removing from a list while looping over it

The loop's iterator keeps an index. When you remove an item, everything after it shifts left, and the next item gets skipped.

2. Changing a dict's size while looping over it

Fix it by looping over a snapshot: for item in list(stock):, or build a new dict with a comprehension: {k: v for k, v in stock.items() if v}.

Challenges

Print each item of colors on its own line without using a for loop. Use iter(), next() and while.

Hint

Catch StopIteration with try/except, or pass a default to next() and stop when you get it.

Show solution
colors = ["red", "green", "blue"]
it = iter(colors)
while True:
    try:
        print(next(it))
    except StopIteration:
        break

Remove every even number from nums and print the list. Keep the first line: the checker also tries other lists.

Show solution
nums = [2, 4, 5, 6, 8, 9]
nums = [n for n in nums if n % 2 != 0]
print(nums)

Recap

  • An iterable can be looped over; iter() turns it into an iterator, which hands out values with next().
  • for = iter() once, then next() until StopIteration.
  • Iterators remember their position and are single-use. zip, map, enumerate, files and generators are iterators.
  • Iterators are lazy: values are produced only when asked for, which saves memory.
  • Do not change the size of a list or dict while looping over it. Loop over a copy, or build a new one.
