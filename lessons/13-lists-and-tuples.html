Data types in depth

Lists and tuples

Lists are Python's everyday arrays: ordered and changeable. Tuples are their fixed, read-only cousin. Slice them, change them, loop over them, and know which to choose.

Lists: slicing and indexing

In other languages this is an "array". Python calls it a list, and it can hold mixed types and grow or shrink. Indexing and slicing work exactly like strings: 0 from the left, -1 from the right, [start:stop:step] with the stop not included.

Changing a list

Lists are mutable, so these all change the same list in place:

To...Use
Replace one itemv[3] = "IJK"
Replace a slicev[1:2] = ["LMN"]
Insert without removing anythingv[2:2] = ["x", "y"] (an empty slice)
Add to the endappend(item), or extend([a, b]) for several
Add at a positioninsert(index, item)
Remove the last item (and get it back)pop(), or pop(index)
Remove the first matching valueremove(value) (an error if it is missing)
Remove by positiondel v[0]

Looping, conditions and comprehensions

A for loop runs its indented lines once per item. An if runs its lines only when the test is true. Both get their own page later, but you need the basics now. A list comprehension builds a new list in one line: [expression for item in sequence], with an optional if to filter.

Copying. copy_list = variety is not a copy: it is a second name for the same list (see the Variables page). Use variety.copy() for a real, separate list. It is a shallow copy: lists nested inside are still shared. The Dictionaries page shows how to get a fully independent copy.

Tuples

A tuple is an ordered sequence like a list, but immutable: once created, you cannot change, add or remove items. Why have one?

  • Safety: data that should not change (coordinates, RGB colours, a fixed set of options) cannot be altered by accident.
  • Dictionary keys: a tuple can be a key or set member, a list cannot.
  • Intent: a tuple says "this is a fixed record". A list says "this is a collection that may grow".

You can index and slice a tuple like a list. Joining two tuples with + builds a new tuple. Unpacking assigns each item to its own name. A one-item tuple needs a trailing comma.

Challenges

Change variety into ["A", "LMN", "CDE", "FGH", "IJK"] by replacing the second item and adding one at the end.

Show solution
variety = ["A", "BC", "CDE", "FGH"]
variety[1] = "LMN"
variety.append("IJK")

Build squares, the squares of 1 to 5, using a list comprehension: [1, 4, 9, 16, 25].

Hint

range(1, 6) gives 1, 2, 3, 4, 5.

Show solution
squares = [x ** 2 for x in range(1, 6)]

Unpack tea_types into first, second and third, then print second.

Show solution
tea_types = ("Black", "Green", "Lemon")
first, second, third = tea_types
print(second)

Recap

  • Lists index and slice like strings, and change in place: append, insert, extend, pop, remove, del, and slice assignment.
  • [expr for x in seq if test] builds a list in one line.
  • b = a shares a list. a.copy() makes a shallow copy.
  • Tuples are immutable: use them for fixed records and dictionary keys. Unpack with x, y, z = t, and remember the comma in (5,).
