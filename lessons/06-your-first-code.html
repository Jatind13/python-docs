Talk to Python: the REPL

In a terminal you start the REPL by typing python (or python3). Here is a one-line-at-a-time version to play with. Python prints the value of an expression automatically, which is why you do not need print() here.

Things to try, one at a time: 2 + 3, 7 * 6, 10 / 4, 10 // 4, 2 ** 10, "ha" * 3, len("python"), then name = "Asha" followed by name. Use the up arrow to bring back a previous line.

This REPL handles one line at a time. In a real terminal, blocks such as if or def continue onto lines starting with .... To leave a real REPL, type exit(), or press Ctrl + D (macOS/Linux) or Ctrl + Z then Enter (Windows).

Run a script from the terminal

Once Python is installed (the next lessons cover it), the workflow is always the same: write a file, then ask Python to run it.

  1. Create a file named hello.py containing print("Hello, world!").
  2. Open a terminal in the folder that contains the file.
  3. Run it with the command for your system.
PowerShell

On Windows, py hello.py also works. The py launcher is installed by the official installer and picks a Python version for you.

Terminal

On macOS, use python3. Plain python may not exist, or may point to something else, depending on how Python was installed.

bash

On Linux, use python3. The version printed will match what your system has installed.

Common problems. python: command not found or "is not recognized" means Python is not installed or not on your PATH. can't open file ... No such file means your terminal is in a different folder than hello.py. We fix both properly in the install lesson. Read the error, it is trying to help

Everyone's code breaks. Python's error messages are specific, and learning to read them is a core skill. Run each version and read the last line first, then the line number.

ErrorWhen it appearsWhat it means
SyntaxErrorBefore anything runsThe code is not valid Python grammar: nothing ran at all.
NameErrorWhile runningYou used a name Python does not know (often a typo or wrong capital letter).
ZeroDivisionErrorWhile runningThe code is valid, but this operation is impossible. Lines before it did run ("Before" printed).

Notice the difference: a syntax error stops everything, while a runtime error only stops the program at the failing line. That difference comes from how Python reads your file, which we cover in How Python works.

Recap

  • You can run Python as a REPL (one line at a time) or as a script (python3 hello.py).
  • print(...) is a function call: a name, parentheses and arguments. Text needs quotes. Names are case-sensitive.
  • A SyntaxError stops everything before it runs. A runtime error stops the program at the failing line.
  • Read an error from the last line upwards: the type and message, then the file and line number.
