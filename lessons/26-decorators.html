Decorators

A decorator wraps a function to add behaviour (timing, logging, caching, access checks) without touching the function's own code. It looks like magic, but it is built entirely from two things you already know: functions are objects, and closures remember variables.

Build one by hand first

A decorator is a function that takes a function and returns a new function, usually one that calls the original with something extra before and after.

The @ syntax is only a shortcut

This...

@announce
def make_chai():
    print("making chai")

...means exactly this

def make_chai():
    print("making chai")
make_chai = announce(make_chai)

The decorator runs once, when the def is executed. The wrapper runs on every call.

A decorator for any function: *args, **kwargs and wraps

The wrapper above only works for functions with no arguments and drops the return value. A real decorator must accept anything, pass it on, and return the result. And it should use functools.wraps, or the decorated function loses its name and docstring (which breaks help(), logging and debugging).

Three real-world decorators

1. Timer: how long did it take?

2. Debug: what went in, what came out?

3. Cache: never compute the same thing twice

The wrapper keeps a dict in its closure. If it has seen these arguments before, it returns the stored answer instead of calling the function. On a recursive Fibonacci that turns an exponential mess into a handful of calls.

Caching works only for pure functions: same input, same output, no side effects. Do not cache something that reads the clock, a file or a database.

Decorators that take arguments

@repeat(3) needs one more layer: repeat(3) is called first and must return a decorator. So it is three functions deep: the argument layer, the decorator, and the wrapper.

Stacking, and the decorators you already know

Several decorators can sit on one function. They apply from the bottom up: the one nearest the def wraps first.

Challenges

Write a decorator shout that makes the decorated function return its result in upper case. It must work with any arguments and keep the function's name (use functools.wraps).

Show solution
import functools

def shout(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

@shout
def greet(name, greeting="hello"):
    return f"{greeting}, {name}"

Write count_calls so that the decorated function gets a calls attribute that counts how many times it has been called. Hint: functions are objects, so you can set wrapper.calls = 0.

Show solution
import functools

def count_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        return func(*args, **kwargs)
    wrapper.calls = 0
    return wrapper

@count_calls
def ping():
    return "pong"

ping(); ping(); ping()
print(ping.calls)

Write a decorator with an argument, retry(times). If the function raises an exception, call it again, up to times attempts in total. If the last attempt also fails, let the exception propagate.

Hint

Three layers, like repeat. Inside the wrapper, loop times rounds with try/except; on the last round, raise again.

Show solution
import functools

def retry(times):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if attempt == times:
                        raise
        return wrapper
    return decorator

attempts = 0
@retry(3)
def flaky():
    global attempts
    attempts += 1
    if attempts < 3:
        raise ConnectionError("network blip")
    return "connected"

print(flaky(), "after", attempts, "attempts")

You finished the refresher

  • A decorator takes a function and returns a wrapped one. @d means f = d(f).
  • Always use *args, **kwargs, return the result, and add functools.wraps.
  • Decorators with arguments add one more layer. Stacked decorators apply bottom up.
