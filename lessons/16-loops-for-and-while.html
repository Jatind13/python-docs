Loops: for and while

Repeat code without copying it. Use for to go through a collection or a number of times, and while to repeat until something changes.

10 min3 challenges3-question quiz

for loops

for item in collection: runs the indented block once per item, with item set to each value in turn. It works on lists, strings, tuples, dictionaries (you get the keys) and range().

CallGives
range(5)0, 1, 2, 3, 4 (the stop value is not included)
range(2, 6)2, 3, 4, 5
range(1, 10, 3)1, 4, 7 (start, stop, step)
enumerate(seq)(position, item) pairs, when you need the index too

while loops

while condition: checks the condition, runs the block, and checks again. It stops when the condition becomes false. You use it when you do not know in advance how many rounds you need.

Infinite loops. If nothing inside a while ever makes the condition false, it runs forever. On this page that freezes the browser tab, so reload it to recover. In a terminal, press Ctrl + C. Always check that something inside the loop changes the condition.

Use for when...Use while when...

Nested loops and indentation

A loop inside a loop runs its whole block for every round of the outer one. Indentation decides what belongs where. Here the print() that ends each line is indented to the level of the inner for, so it runs once per row. Indent it one more level and it would run once per cell.

Challenges

Use a loop to add the numbers 1 to 100 into total, then print it (5050).

Hint

range(1, 101) gives 1 up to 100.

Show solution
total = 0
for n in range(1, 101):
    total += n
print(total)

Use a while loop to print 5, 4, 3, 2, 1 on separate lines, then Go!

Show solution
count = 5
while count > 0:
    print(count)
    count -= 1
print("Go!")

Print the 7 times table for 1 to 5, one per line, like 7 x 1 = 7.

Show solution
for i in range(1, 6):
    print(f"7 x {i} = {7 * i}")

Recap

  • for x in collection: runs the block once per item. range(start, stop, step) excludes the stop. enumerate adds the position.
  • The accumulator pattern: start a variable before the loop and update it inside.
  • while condition: repeats while the condition is true. Something inside must change it, or it never ends.
  • Indentation decides which lines are inside a loop, and which loop they belong to.
