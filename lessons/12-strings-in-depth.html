Indexing and slicing

A string is a sequence, so every character has a position: 0 from the left, -1 from the right. A slice is written [start:stop:step]. The stop position is not included, and any part can be left out.

SliceMeaning
s[0:6]Positions 0 to 5
s[:6] / s[7:]From the start up to 5 / from 7 to the end
s[:]The whole string (a copy)
s[-4:]The last four characters
s[0:6:2]Every second character (the step, or "hopping")
s[::-1]Reversed (a step of -1)

The methods you will use daily

Strings are immutable, so every method returns a new string and leaves the original alone.

MethodWhat it does
lower(), upper()Change the case
strip()Remove spaces (or other characters) at both ends. Also lstrip(), rstrip()
replace(old, new)Replace every occurrence
find(text)Position of the first match, or -1 if missing
count(text)How many times it appears
startswith(), endswith()Yes or no checks on the ends
len(s)Number of characters (a function, not a method)

Split, join and format

split() turns a string into a list. join() does the opposite: it is called on the separator and given the list. For building text from values, use f-strings, or format() where {} marks a placeholder.

Looping over a string, and repr vs str

A for loop repeats its indented line once per item, here once per character. (Loops get their own page later.) Also useful to know: str() gives the readable form, repr() gives the precise form with quotes and escapes, and print() shows the str() form.

Escape sequences and raw strings (r"...") were covered in Text essentials.

Challenges

Print only the word Chai from the string, using a slice with a negative index.

Show solution
chai = "Masala Chai"
print(chai[-4:])

Remove the outer spaces, then split the text on ", ". Print the resulting list: ['Lemon', 'Ginger', 'Mint'].

Show solution
raw = "  Lemon, Ginger, Mint  "
print(raw.strip().split(", "))

Turn the list into the single string Lemon-Ginger-Mint and print it.

Show solution
flavours = ["Lemon", "Ginger", "Mint"]
print("-".join(flavours))

Recap

  • Slice with [start:stop:step]: the stop is excluded, negatives count from the end, and [::-1] reverses.
  • Methods return new strings: lower, upper, strip, replace, find, count.
  • split() makes a list, "sep".join(list) makes a string. Use f-strings (or format) to build text.
  • in asks "does it contain", and repr() shows exactly what a string holds.
