The basics

Challenge set

Six mixed challenges on everything from pages 1 to 6. No new teaching: just use what you know. Each one is checked when you press Check answer.

15 min0 of 6 solved

Ask for the user's name with input() and print Hello, Asha! (with whatever name was typed).

Show solution
name = input("Name: ")
print(f"Hello, {name}!")

Using the two variables, print Total: 750. Let Python calculate the total.

Show solution
price = 250
quantity = 3
print(f"Total: {price * quantity}")

With escape sequences, print exactly these two lines (a tab between the words):

Name	Score
Asha	92
Show solution
print("Name\tScore\nAsha\t92")

Read an age with input() and print how many years are left until 100, in the form 70 years to go for an age of 30.

Hint

input() returns text, so convert it before subtracting.

Show solution
age = int(input("Age: "))
print(f"{100 - age} years to go")

Using the two variables, print Lovelace, Ada.

Show solution
first = "Ada"
last = "Lovelace"
print(f"{last}, {first}")

Make backup an independent copy of items, then add "milk" to items only. After the code, backup must still be ["eggs", "bread"].

Show solution
items = ["eggs", "bread"]
backup = items.copy()
items.append("milk")
