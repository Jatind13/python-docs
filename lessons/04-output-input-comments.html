print() in practice

print() takes any number of arguments and has two options worth knowing: sep (what goes between arguments, a space by default) and end (what goes after the last one, a newline by default).

f-strings: the clean way to mix text and values

Put f before the opening quote and write variables or expressions inside { }. A format after a colon controls how it looks, for example :.2f for two decimals.

input(): ask the user

input("prompt") pauses, waits for the user to type and press Enter, and returns what they typed as a string, always. Even if they type 30, you get the text "30". Convert it with int() or float() before doing math. (In this page, pressing Run shows a small dialog to type into.)

If the user types something that is not a number, int("abc") raises a ValueError. Handling that properly comes later with try/except.

Comments

A comment starts with # and runs to the end of the line. Python ignores it.

  • Explain why, not what. x = x + 1 # add one is noise. # retry once because the API is flaky is useful.
  • No block comments. Python has no multi-line comment syntax. Use several # lines. In VS Code, select lines and press Ctrl + / to toggle comments.
  • Docstrings are different. A triple-quoted string placed first inside a function or file documents it. It is a string, not a comment. You will meet them with functions.

Challenges

This prints 2026 10 15. Change it to print 2026-10-15 using sep.

Show solution
print(2026, 10, 15, sep="-")

The age is already read as a number. Print Next year you will be 31. for an age of 30. Calculate it from the age variable.

Show solution
age = int(input("How old are you? "))
print(f"Next year you will be {age + 1}.")

Using the two variables and an f-string, print exactly Asha scored 92 points.

Show solution
name = "Asha"
score = 92
print(f"{name} scored {score} points")

Recap

  • print(..., sep=" ", end="\n"): multiple arguments, and control over what separates and ends the output.
  • f-strings (f"{name}") are the clean way to put values in text.
  • input() always returns a string: convert with int() or float().
  • Comments start with #. Write the why, not the what.
