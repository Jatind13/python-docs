Every value has a type

Every value in Python has a type, and type() tells you what it is. The type belongs to the value, not to the variable name (see the Variables page). Here are the core types side by side:

Also worth knowing: None is a special value meaning "nothing here". Advanced topics such as decorators and generators come in later pages.

Numbers and booleans

There are two number types you use daily: int (whole numbers, as large as memory allows) and float (decimals, stored approximately). A bool is a kind of int: True acts like 1 and False like 0.

The last line shows truthiness: zero, empty values and None count as False. Everything else counts as True, including the string "0", because it is not empty.

Strings, lists and tuples

These three are sequences: ordered, indexable from 0, and sliceable. They share len(), indexing, in and slicing.

Dictionaries and sets

A dictionary maps keys to values and is the right tool whenever you look things up by name. A set stores unique items with no order and is fast for "is it in here?" checks.

Picking a type. Ordered and changing: list. Fixed group: tuple. Look up by name: dict. Unique items or fast membership: set. Keys of a dict and items of a set must be immutable, so a tuple can be a key but a list cannot.

Challenges

Create unique from names so each name appears once, then print how many unique names there are (it should print 3).

Show solution
names = ["asha", "ravi", "asha", "li"]
unique = set(names)
print(len(unique))

Print the price of a banana by looking it up in the dictionary, then add a "mango" priced 70.

Show solution
prices = {"apple": 40, "banana": 10}
print(prices["banana"])
prices["mango"] = 70

a and b are strings. Print their sum as numbers, 12, not the joined text 57.

Show solution
a = "5"
b = "7"
print(int(a) + int(b))

Recap

  • Core types: number (int, float), string, list, tuple, dict, set, bool. Plus None for "nothing".
  • Strings, lists and tuples are ordered sequences. Dicts look up by key. Sets hold unique items.
  • / gives a float, floats are approximate, and zero, empty values and None are falsy.
  • Convert with int(), str(), list(), set() and friends.
