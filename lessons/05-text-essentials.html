Strings in a minute

A string is text. Use single or double quotes (same thing), and triple quotes for text over several lines. Strings are immutable: methods give you a new string and leave the original alone.

Special characters

Some characters have a special job in Python code. This is the short list worth knowing:

CharacterJobExample
#Starts a commentx = 1 # note
" 'Start and end a string"hi"
\Escape character inside strings"a\nb"
:Starts an indented block, and slicesif x > 1:, s[0:3]
( )Calls a function, groups math, tuplesprint(x)
[ ]Lists and indexing[1, 2], s[0]
{ }Dictionaries, sets, f-string placeholders{"a": 1}, f"{x}"
_Allowed in names, a throwaway name, digit separatormy_var, 1_000_000
* ** // %Multiply, power, floor division, remainder2 ** 3 is 8, 7 // 2 is 3, 7 % 2 is 1
@Decorators (later), matrix multiply@app.get("/")

The catch: the quote and backslash characters are special inside strings too. That is what escape sequences solve.

Escape sequences

A backslash followed by a character means "treat the next character specially".

SequenceMeans
\nNew line
\tTab
\\A literal backslash
\" and \'A quote character inside a string with the same quotes
\u00e9A Unicode character by its code (here: é)

print() shows the result of escapes. repr() shows the string the way you would write it in code, which is handy for seeing hidden characters.

Raw strings

Put r before the quote and backslashes stop being special. Use it for Windows paths and regular expressions. A raw string cannot end with a single backslash.

Challenges

Print the letters A, B and C on three separate lines using a single print() call and \n.

Show solution
print("A\nB\nC")

This should print C:\new\table but the escapes break it. Fix it.

Hint

Either put r before the quote, or double every backslash.

Show solution
print(r"C:\new\table")

Print exactly She said "Hi", including the double quotes.

Show solution
print('She said "Hi"')

Recap

  • Strings are immutable text. Use len, indexing, slicing and methods like strip, upper, replace, split.
  • Symbols like #, :, [ ], { }, \ each have a specific job.
  • Escapes: \n newline, \t tab, \\ backslash, \" quote. Use r"..." to switch them off.
