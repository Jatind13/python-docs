Two ways to run Python

WayWhat it isUse it for
REPLAn interactive prompt (>>>). You type a line and Python answers at once. Start it with python (or python3).Quick experiments
ScriptA .py file that Python runs top to bottom: python hello.py (or python3 hello.py).Real programs

Try the REPL below. Python prints the value of an expression by itself, so you do not need print() here. Try 2 + 3, "ha" * 3, len("python"), then x = 10 followed by x * 2. The up arrow brings back earlier lines.

To leave a real REPL type exit(), or press Ctrl + D (macOS/Linux) or Ctrl + Z then Enter (Windows).

Hello, world

Press Run, or Ctrl + Enter inside the box. The first run takes a few seconds while Python loads.

The parts of that line:

  • print is a built-in function. Names are case-sensitive, so Print would fail.
  • ( ) calls the function. What you put inside are the arguments.
  • "Hello, world!" is a string: text in quotes. The quotes are not printed. Single quotes work too.

print("2 + 3") prints the text 2 + 3. print(2 + 3) does the math and prints 5. Quotes mean "this is text".

Run it as a script

Save print("Hello, world!") in a file called hello.py, open a terminal in that folder, and run it. (Python must be installed, see the previous page.)

python hello.py
py hello.py          # the launcher also works
python3 hello.py

If you see command not found or "not recognized", Python is not on your PATH. If you see No such file, your terminal is in a different folder than hello.py. In VS Code you can also click the Run triangle.

Read the error

Errors are information, not failure. Read the last line first (the error type and message), then the line number above it.

ErrorMeaning
SyntaxErrorThe code is not valid Python. Nothing runs at all.
NameErrorA name Python does not know: usually a typo or the wrong capital letter.
IndentationErrorLines are indented inconsistently. Python uses indentation to group code.
ZeroDivisionError, TypeError, ValueErrorValid code that fails at run time. Earlier lines already ran.

Recap

  • REPL for quick experiments, a .py script for real programs: python3 hello.py.
  • print(...) is a function call. Text needs quotes, and names are case-sensitive.
  • Read errors from the last line up. A syntax error stops everything, a runtime error stops at the failing line.
